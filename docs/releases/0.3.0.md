# ClipMill 0.3.0 — Editorial AI on Windows and Linux

ClipMill can now use a local editorial model to propose and review clips on Windows and Linux, alongside the existing Apple silicon support.

## What changed

- **Editorial AI on Windows and Linux:** the editorial component carries a pinned llama.cpp server. It uses Vulkan on a suitable graphics card and falls back to the processor.
- **Model choices:** Qwen3.5 9B and a lighter Qwen3.5 4B GGUF model are available. You can also add your own GGUF model with its vision projector. Models only shows choices this computer can run; MLX choices appear on Apple silicon.
- **Setup:** download the Editorial AI component and a model in Setup or Models. ClipMill checks that the model runs before analysis uses it. Processor-only computers can take several minutes for the check and for analysis. The built-in picker remains available without an editorial model.

Windows support remains in beta. Download the installer for your platform below, then follow the [installation guide](https://github.com/Macmilan24/clipmill/blob/v0.3.0/docs/install.md). Model weights are downloaded in the app during setup. `SHA256SUMS.txt` lists the digest of each installer.
