# ClipMill 0.5.1

- **Whisper on older Windows PCs.** Speech recognition now selects a native
  build that matches the processor. This fixes the repeated “Recognise
  speech” failure on AVX processors such as the Intel Core i7-3770. It also
  keeps Whisper available for recordings in languages Parakeet does not cover.
- **Windows upgrades.** You can install directly over 0.4 or 0.5.0. Existing
  Studio shortcuts still open Studio, and the `clipmill` command works for
  the terminal and connected MCP clients. This also restores the command if
  the 0.4 to 0.5.0 upgrade removed it.
- **Clip suggestions.** When the editorial markup marks too much of a
  recording for removal, the cutter also considers the original moments. A
  short recording can again yield usable suggestions in Results.

**Upgrading an existing Windows installation.** Close Studio and run the
installer. Open **Models → Components** and choose **Update**. After
**Transcription** finishes updating, run the affected analysis again. You can
reuse the model weights and projects already on your PC. [Installation guide](../install.md)
