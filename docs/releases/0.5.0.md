# ClipMill 0.5.0

ClipMill adds a local recognizer with native word timing, search across a
recording's transcript and remembered moments, and a command-line and MCP
interface for working with the same projects as the Studio.

- **Word timing.** Install Parakeet TDT v3 in Models for recordings in its 25
  supported languages. It timestamps words as it recognizes them. Readiness
  uses the recording language when checking which models it needs.
- **Recording search.** Find timecoded passages by words, speaker or chapter.
  Installing the local meaning-search model also finds passages with related
  wording.
- **Connected clients.** Give each client its own scopes, review the activity
  log, and revoke it from Settings. Supported MCP clients can reconnect to a
  running task, read an edit document and ask for rights before export.
- **Editing from a client.** Read an edit's revision, apply a batch of
  commands, inspect its history or undo the latest change. The engine also
  exposes recording details, paged job events and each client's own audit log.
- **Memory use.** The scheduler accounts for models already loaded and defers
  background work when higher-priority work needs the memory.

## Measured analysis time

On an Apple silicon Mac, a 112.96-second
English recording took 31.77 seconds on average with 0.4 and 23.32 seconds
with 0.5, a 26.6% reduction. Each run requested five clips of 20–90 seconds
and disabled cloud and optional editorial inference. The test used release
binaries, locked worker dependencies and a fresh daemon, workers and artifact
store for every run. The installed model files and operating-system cache
were shared.

| Run | Version | Analysis time |
| --- | ------- | ------------- |
| 1   | 0.4     | 37.41 s       |
| 2   | 0.5     | 26.16 s       |
| 3   | 0.5     | 20.48 s       |
| 4   | 0.4     | 26.12 s       |

Word timing averaged 14.82 seconds with Whisper and its forced aligner in
0.4 and 0.031 seconds with Parakeet's native timing in 0.5. Recognition alone
averaged 15.32 and 15.82 seconds, respectively. The pipelines produced 344
and 342 words. This comparison covers one recording and two runs per version.
Transcript accuracy and the quality of the suggested clips were not scored.
