# ClipMill 0.4.0 — Activity, update notices and fixes

This release makes long work easier to follow, says when a new version is out, and fixes Editorial AI on Windows.

## What changed

- **Editorial AI works on Windows:** in 0.3.0 the check that proves the editorial model runs could not finish on Windows, so the model was never used there. It completes now, and Models shows how fast the model ran on this computer, warning when an analysis would be slow.
- **Activity tray:** a button at the top of the window counts what is running (analyses, exports, model downloads, installs, imports and uploads) and shows how far each has come. When an analysis or export finishes while ClipMill is in the background, the window asks for your attention.
- **New version notice:** once a day ClipMill asks GitHub which release is newest and links to it when there is a newer one. Nothing is downloaded or installed, and Settings → About turns it off.
- **Settings and Models:** Settings gains review preferences (the next clip after a decision, the playback speed) and defaults for export folders, file names and the caption look of new projects. Models shows each job's model in use and folds the others away.
- **Fixes:** analysing one recording in two projects no longer fails when one is cancelled, and transcripts no longer contain markers such as `[BLANK_AUDIO]`.

Windows support remains in beta. Download the installer for your platform below, then follow the [installation guide](https://github.com/Macmilan24/clipmill/blob/v0.4.0/docs/install.md). `SHA256SUMS.txt` lists the digest of each installer.
