# ClipMill 0.6.0

Give a recording an editorial brief in New Project or Results. ClipMill can build a clip from several parts of the recording, show why each part made the cut, and check whether the cuts preserve what the speaker said.

## Finding and reviewing clips

- Ask for a topic, an answer, or a recurring theme. Results shows matching passages with timecodes so you can inspect the source before proposing a cut.
- Each proposed clip has a form, ordered parts, joins and a keep score. The Inspector shows the critic's findings and any doubts about the edit. When no plan clears review, Results shows the empty ranking.
- Try a shorter duration or a different brief. ClipMill reuses the transcript, timing and recording memory. The original results remain available in their analysis run.
- Keep or reject a proposal and optionally give a reason. Later briefs in the same project can use those choices and recent editing actions.

## Editing and automation

Open a plan in the editor to review the source ranges, restore a cut, or adjust a join. Preview and export use the same edit document. Room tone is taken from the source interval associated with the cut.

The local engine and MCP expose memory search, proposals, decisions and plan creation. Edit commands use the revision you last read, and a batch either applies in full or leaves the document at its previous revision. The shell command below produces a second set of clips from a completed run.

```sh
clipmill reprompt "$PROJECT" "$SOURCE" "Find the clearest answer to the opening question" \
  --run "$JOB" --min 15 --max 40 --count 2 --wait
```

The built-in picker remains available for recordings analyzed without the local editorial model. Saved edits and rankings from earlier versions can still be opened.

## What changed on one recording

We compared the first result shown by each version on the same 113-second
English recording and initial brief. Version 0.5 offered one 31.72-second
clip marked for review. In 0.6, two cuts passed the critic. The first ended
on the speaker's privacy conclusion at 24.76 seconds. The second kept both
amounts and the conclusion of a cost comparison in 31.48 seconds. A second
brief requested a specific example under 45 seconds. Both existing cuts
already met that limit and ranked in the same order. Asking for every mention
of memory produced a different edit. Its 45.60-second montage kept all five
mentions across three passages, and both joins passed review. All three
working previews decoded in full. The narrated recording uses test bars, so this
comparison measures editorial choices and captions.
