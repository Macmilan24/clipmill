# Decision Register

The load-bearing decisions, each with the test that would falsify it. A
decision whose falsification test passes gets revisited — this register keeps
the architecture honest as the field moves. D-decisions come from the system
design book (Appendix D); R-decisions are repo-local implementation choices
made where the book is silent or ambiguous.

## D — Design-book decisions

| ID  | Decision                                                                                   | Falsification test                                                                                                                              |
| --- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| D01 | Local-first with orchestration width compensating for model size; API collapses the funnel | Ablation: local ensemble cascade vs. single local call vs. single API call, per genre — if width buys <2 points of blind preference, narrow it. |
| D02 | Parity as a six-component vector with per-genre non-inferiority                            | Blind protocol detects a failed genre that aggregate scoring would have hidden.                                                                 |
| D03 | Rust daemon + Python model workers + Tauri/React shell                                     | Kill drills and dependency-conflict injections cost only leased tasks; if a worker crash ever corrupts state, the boundary failed.              |
| D04 | SQLite + filesystem CAS; no server stack on desktop                                        | Profiling shows metadata or artifact I/O as a top-3 bottleneck on any tier.                                                                     |
| D05 | Content-addressed artifacts; state/evidence separation                                     | Cache hit rate on repeat analysis <95%, or any migration incident touching evidence.                                                            |
| D06 | Rational time everywhere; no float seconds in records                                      | VFR round-trip fixtures drift ≥1 tick.                                                                                                          |
| D07 | Specialists always-on; VLM event-triggered                                                 | Ablation: uniform VLM sampling beats triggered VLM on quality-per-joule on any tier.                                                            |
| D08 | Separate ASR / alignment / diarization / ASD stages                                        | An integrated model beats the pipeline on word timing _and_ attribution _and_ cost, per language.                                               |
| D09 | Evidence graph + hierarchical memory over flat context                                     | Ablation: flat-transcript prompting matches packet prompting on hour-long sources.                                                              |
| D10 | Proposer mesh over single scorer                                                           | One proposer's recall envelope covers the mesh across all launch genres.                                                                        |
| D11 | Pairwise judge ensembles + Bradley–Terry over absolute scores                              | Absolute scoring matches pairwise on ranking stability and calibration at equal cost.                                                           |
| D12 | Boundary lattice as a separate optimization stage                                          | End-to-end span prediction meets the boundary-repair SLO without it.                                                                            |
| D13 | One Edit IR for preview, render, and export                                                | Any release where golden preview/render parity fails — the invariant, not the decision, is then the bug.                                        |
| D14 | Scene-level layout DP + crop-path optimization over per-frame tracking                     | Smoothed per-frame tracking passes the jerk/identity gates on the reframe benchmark.                                                            |
| D15 | Retrieval-first B-roll; generation opt-in with provenance                                  | Users on the blind protocol prefer generated default B-roll _and_ the rights ledger can carry it.                                               |
| D16 | Deny-by-default network broker; Local Lock OS-enforced                                     | Packet capture in CI ever shows an egress attempt in Lock mode — this one is allowed **zero revisits**.                                         |
| D17 | Evaluation service as a subsystem; gates over dates                                        | A gated release that meets its gates and still regresses in the field beyond tolerance.                                                         |
| D18 | Per-capability quantization policy; embeddings 8-bit minimum                               | 4-bit embeddings show no retrieval regression on the internal benchmark.                                                                        |
| D19 | Backend selection by measured device profile                                               | Static per-platform defaults match measured selection within 5% on the device matrix.                                                           |
| D20 | Export-first; publishing as adapter with human approval                                    | Platform API terms and audit posture change to make first-party publishing low-risk at launch scale.                                            |

| R19 | A stage names a capability, not a model; which implementation serves it is resolved once at plan time from the last verified device profile and frozen onto the task, and the benchmark behind that profile is believed only where it names this machine's fingerprint and the currently pinned model digests | D19 says selection is measured, and a per-stage model name is a static per-platform default in disguise. The daemon cannot take the measurement itself — a model's cost is only observable inside the environment that loads it — so the measurement is taken by `tools/bench/speech-benchmark.py` in the daemon's private state directory and bound to hardware and weights rather than trusted. Two implementations of one capability produce different bytes, so the chosen one reaches the artifact key through `producer.model_digest`: artifact identities become device-dependent by design, and re-measuring a device moves only what is planned next. | R20 | The evidence index publishes two levels and no more: L1 is what the recording states about itself, L2 is lexical cohesion named as an approximation, and every unit carries the transcript word range it was derived from                                                                                     | Book ch. 14 asks for scenes and topics. Nothing available at P1 understands the words, so the honest options were to approximate or to omit — and an approximation published under the name of the thing it approximates is the failure mode that matters, because the stage that consumes it cannot tell. So the unit is a lexical neighbourhood, the schema says so, and the parameters that produced it travel in the document and in the artifact key. L3 and open-loop detection are omitted rather than approximated: both would need comprehension, and a placeholder would be leaned on. Provenance is a word-index range rather than copied text, so an index and its transcript cannot come to disagree (Rule 14.1). Two guards keep the segmentation from always finding something — a minimum gap count, because a cutoff over three samples is not a distribution, and an absolute depth floor, because the deepest of three near-identical valleys is noise. Evidence interval tables in SQLite are deferred to Phase 2; artifact reads suffice at P1 scale. Revisit when a model that reads the words is admissible under the local-only constraint, through a versioned index block.                                                                                                                                                                                                                                                        |
| R21 | Discovery nominates and never chooses: three proposers of the design's ten, each naming its approximation in a rubric string, every candidate carrying a full legal lattice, walkable evidence, and a cluster identity                                                                                        | Book ch. 15 wants ten proposers and an embedding-based clusterer. Seven of the ten read face affect, motion, OCR, or speaker turns, none of which this phase measures, and a proposer nominating on evidence it never took is worse than an absent one. The three that ship are approximations and say so where a reader will see it: `topic-span-open-close.v1` is not a narrative model, and the rubric reaches the artifact key so a changed method cannot reuse a cached set. The lattice is kept whole rather than resolved, because boundary optimization has more information than discovery and a pre-chosen boundary is a decision made by whoever had least reason to make it. Φ carries only the terms that can be evaluated — mid-word structurally, duration, coverage — and omits open loops, identity, rights, and layout rather than passing them, since a term recorded as never firing reads like a term that was checked. Clustering is interval and evidence overlap for want of an embedding, and keeps every member so a diversity decision can be shown. Revisit each proposer as its signals become measurable, through the versioned rubric rather than in place.                                                                                                                                                                                                                                                                  |
| R22 | Ranking shows its work: eight named axes with an axis nobody measured reported unavailable rather than zero, a boundary published beside the runner-up it beat, and a set smaller than the one requested that accounts for the difference                                                                     | Book ch. 16 decomposes the score so a user can argue with it, and a decomposition is only worth having if every part of it traces to something that happened. Three of the eight axes cannot be measured at this phase — there is no prompt, no vision, and craft needs audio — so they report `available: false` with a reason and contribute nothing. Scoring them zero would read as a measurement of badness and a neutral default would read as a measurement at all; either lets an axis nobody evaluated move a number a user is asked to trust. Feasibility is the counter-case and stays available at one, because fit is always legal and that is a real measurement with a constant answer. The displayed number is a percentile within one recording's cohort and is named `display_score` beside the raw score so nobody stores it as a probability. J is exhaustive over the lattice rather than heuristic, because the design keeps it under a few hundred pairs and a search that small should not be approximated; the speech rules are terms rather than filters, so a strong enough hook can still buy a cold open. A short set states its reason rather than padding, because padding is how a tool teaches a user to stop trusting its ordering. Weights are hand-set and every rubric string reaches the artifact key, so calibration against human labels arrives as a new version rather than as a silent change to cached answers. |
